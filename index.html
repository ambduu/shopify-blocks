Open source · MIT · Works with any Online Store 2.0 theme

Shopify sections you own.

Beautiful, accessible sections you drop straight into your theme. No app to install. No monthly fee. No script tags slowing your store down. Just Liquid, CSS and a little JS — yours to edit.

$ npx github:ambduu/shopify-blocks add faq-accordion

Run it inside your theme folder. Then open the theme editor → Add section.

Built for AI coding agents too

shopify-blocks ships an agent skill for Claude Code and a rule for Cursor. Your agent learns which blocks exist, installs them with one command, and writes new sections that follow Shopify best practices — scoped CSS, presets, block.shopify_attributes, responsive images, accessibility.
